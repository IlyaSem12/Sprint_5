# Финальный проект 5 спринта

## Описание
Проект содержит UI-автотесты для веб-приложения для 5 спринта яндекс практикума.

Покрытые сценарии:

* Регистрация пользователя
* Авторизация пользователя
* Выход из аккаунта
* Создание объявления (авторизованным и неавторизованным пользователем)

Тесты написаны на **Python + Selenium + Pytest**.

---

## Структура проекта

```
Sprint_5/
│
├── tests/
│   ├── test_registration_user.py
│   ├── test_login_user.py
│   ├── test_logout_user.py
│   └── test_creating_ad.py
│
├── conftest.py        # фикстуры
├── locators.py        # локаторы элементов
├── test_data.py       # dataclass с тестовыми данными
├── config.py          # конфигурация (URL, константы)
├── pytest.ini
├── requirements.txt
└── README.md
```

---

## Используемые технологии

* Python 3.10.11
* Selenium
* Pytest
* uuid (генерация тестовых данных)
* Requests (авторизация через API)

---

## Покрытые сценарии

### Регистрация

* Успешная регистрация
* Редирект на главную
* Отображение аватара и имени
* Ошибки при:

  * неправильном email
  * существующем пользователе
  * невалидных данных

### Авторизация

* Успешный вход
* Редирект
* Отображение аватара
* Отображение имени

### Выход из аккаунта

* Отображение кнопки «Вход и регистрация»
* Отсутствие аватара
* Отсутствие имени

### Создание объявления

* Неавторизованный пользователь видит модальное окно
* Проверка появления объявления в профиле («Мои объявления»)

---

## Особенности реализации

* Используются `WebDriverWait` и `expected_conditions`
* Тестовые данные оформлены через `dataclass`
* Генерация уникальных значений через `uuid`
* Разделение логики:

  * `locators.py` — только локаторы
  * `config.py` — только конфигурация
  * `test_data.py` — только тестовые данные

---

## Архитектурные решения

* Каждый тест заканчивается `assert`
* Локаторы вынесены в отдельный модуль
* Повторяющаяся логика реализована через фикстуры
* Авторизация вынесена в API-фикстуру для ускорения тестов
